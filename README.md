# Vertex Quant (极值量化) - 前端项目

## 项目说明

虚拟币量化交易平台前端

## 技术栈

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## 开发说明

```sh
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 目录结构

```
src/
├── api/           # API 层（后端对接时填充）
├── types/         # 类型定义
├── components/    # 组件
├── pages/         # 页面
└── hooks/         # 自定义 Hooks
```
