# Security Policy

[English](SECURITY.md) | [简体中文](SECURITY.zh-CN.md)

## Supported Code

Security fixes are applied to the latest revision of the `main` branch.

## Reporting a Vulnerability

Do not disclose a suspected vulnerability in a public GitHub issue, discussion,
pull request, or social post.

Use GitHub's private vulnerability reporting flow:

<https://github.com/Cheny099/Vertex/security/advisories/new>

Include the affected revision, reproduction steps, expected impact, and a
minimal proof of concept when possible. Remove credentials, access tokens,
personal data, and production infrastructure details from the report.

This repository contains the frontend only. If a report depends on backend
behavior, identify the relevant request and response contract without including
private backend credentials or deployment details.

Please allow time for the report to be validated and remediated before public
disclosure.
